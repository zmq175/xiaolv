# SPEC-022：模型选择原生成员通知

状态：Verified（本地完整链路，真实供应商与 QQ 待验收）。沿用在线入口、回放入口和发送边界。

群聊模型在结构化输出中给出 text 与 mentions（当前输入 member_ref 数组）；空数组表示不通知。只有组合层启用的会话展示此能力。服务端从经过范围校验和长度裁剪的当前上下文提供 member_ref，模型不能直接指定 QQ 号、昵称或 all。选择未知引用导致 model_error，不发送。运行时再次检查解析后的账号属于当前会话上下文，再交由动态成员准备、TTL/epoch 和幂等出口。

保持纯文字模型/回放兼容，新增 TextReply 承载文字及账号引用。这一增量先使用前置 mention + text 形式，后续有序 segments、引用与媒体统一计划仍属目标，不能宣称已实现。

# SPEC-036：版本历史、差异与网页回滚

状态：Verified（本规格限定范围），沿用管理HTTP和浏览器测试边界。

GET /admin/api/profile/releases提供认证后的倒序历史列表，limit默认20、范围1–50；before为正整数版本上界（不含），游标按版本而非offset。返回items（version、created_at、name）与next_before，列表不返回人设正文。新发布不会挤动后续页。

网页可读取/继续加载历史，选择版本时读取不可变快照，与当前已发布内容逐字段对照；回滚生成新发布，保留草稿，不修改历史。预览本身不执行回滚。未保存编辑时禁止回滚，避免丢失本地修改；执行复用管理版本、幂等键、权限和未知结果恢复。加载和选择故障不触发写入，显示重试。不同版本请求交错返回不得显示错误目标。

编辑区域同时提供已保存草稿对当前发布的差异，未保存内容不冒充发布候选。文字/换行原样以文本呈现，不渲染HTML。没有发布时标明首次发布。

- AC1：HTTP空历史、降序分页、插入新发布后续页稳定；限制校验和认证。
- AC2：浏览器查看保存草稿的差异，选择历史预览、回滚生成新版本，刷新后草稿仍保留。
- AC3：历史加载错误可重试，目标快照切换不会竞态覆盖；回滚继承并发/幂等错误路径。
- AC4：桌面和手机无横向溢出，版本选择及差异可读，真实浏览器验证。

不提供删除版本或回写历史；运行实例概览、动态权限另行实施。无迁移。

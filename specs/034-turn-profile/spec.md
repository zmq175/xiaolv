# SPEC-034：聊天回合固定已发布人设

状态：Verified（本规格限定范围）。沿用已确认的管理HTTP、聊天回放及日志边界，内部自主决定。

管理员发布的BotProfile必须进入真实聊天模型提示。每个回合在发送配额预检查通过后、参与判断前读取一次当前发布，在原回合截止时间内完成；参与判断与回复使用同一份不可变快照。并发回合不修改共享模型实例的人设。发布发生在读取之后，只影响随后读取的回合。草稿不参与聊天；尚无发布时沿用启动配置。数据库读取失败终止为profile_error，不静默回退；读取超时沿用expired。无发送额度或已过期不读取配置。

聊天只读app发布表，不读取admin草稿和会话。在线启动配置接入此读取路径。日志记录回合event_id、发布version或startup来源，不记录人设正文。该记录说明某回合已选择版本，不等于所有聊天实例都已采用，不伪造管理端全局生效确认。

- AC1：保存草稿不生效，发布后新回合模型提示使用发布内容；回合中发布新版本不改变当前回复，但下一回合采用新版本。
- AC2：回滚后新回合采用回滚产生的新发布，日志标明实际版本；无发布使用启动人设。
- AC3：读取失败/超时无模型调用、无发送；保持原TTL；过期/限流不读取配置。
- AC4：在线服务连接同一发布读取能力，旧文字、@、引用与配额行为回归通过。

不包含网页编辑、持续心跳/管理端运行版本概览或会话撤权。本规格没有数据库迁移。

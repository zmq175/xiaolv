# SPEC-019：原生引用回复发送

状态：Verified（可信映射、协议与持久化；在线模型接线待完成）。沿用已确认的 DeliveryService 公共测试边界。

普通文本、成员 @ 和引用回复是独立语义。DeliveryRequest.reply_to 是可空的内部消息引用；OneBotSender 从可信的、按会话隔离的 reply_messages 映射解析为平台消息 ID。它不能接受模型自由填写的平台 ID。引用段放在正文前，可与显式 mentions 组合；引用本身不自动添加 at 段。

- AC-001：已登记引用生成原生 reply 段，保留普通 text；负的非零 int32 消息 ID 有效。群聊、私聊均按原路由发送。
- AC-002：未登记、跨会话、零、布尔值、越界 ID 在本地拒绝为 not_sent，不调用平台；未请求引用时保持原行为。
- AC-003：引用与 @ 可组合；outbox 持久化 reply_to，重启不重发，修改引用目标视为幂等载荷冲突；历史纯文字记录升级后仍可读取。
- AC-004：过期和旧回合引用沿用统一发送保护，不因引用延长 TTL。

本规格只验证可信引用映射到原生协议及持久化。模型选择、在线上下文候选映射与引用失效预检在后续接线完成前不宣称上线。入站已保留 reply 段，理解其对应上下文仍须接线。

SnowLuma 参考提交 1ef9a2c33023b5fcb400865c8281d2dfd190540b 的 element-codecs.ts 允许负的消息 ID；目标解析失败可能丢弃 reply 段而继续发送正文。get_msg 只返回缓存事件，并不暴露 sequenceAuthoritative，不能单靠 get_msg 成功证明引用可构造。因此 confirmed 只表示发送接口返回成功，不能声称 QQ 引用显示已验证。在线启用前需解决适配器可观测性并进行真实客户端验收；不支持或可判定无效的引用不得主动降级为普通文字。

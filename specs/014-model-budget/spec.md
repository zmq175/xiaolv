# SPEC-014：模型预算预留与持久费用账本

状态：Verified（仅本规格范围）。回放入口观察是否调用外部HTTP/发送，配置与审计查询观察额度；沿用已确认测试边界。

ChatCompletionsGateway可绑定ModelBudget接口：获得并发名额后、HTTP之前reserve(intent)，结束时settle(report)。call_id在预留前生成并贯穿审计，PG不可用/不足额/配置冲突时不调用模型；不足额或配置冲突由TextRuntime返回budget_denied，存储故障返回model_error。生产接线必须绑定预算；不绑定只用于既有协议回放。

BudgetPolicy必须显式提供pool_id、provider_id、model、price_version、模型月额度及人民币每百万输入/输出token单价，可提供缓存输入价。根据2026-09-29用户澄清，模型调用额度独立配置，不受200元部署成本参考限制；宿主机、备份等单独评估。金额使用Decimal与numeric(20,6)，向上取微元，禁止浮点金额。测试价格为合成价格。

- AC-001：真实PG原子预留，余额不足时HTTP零调用；已完成调用的预留/实际费用与内容无关用量审计持久化，重建连接不丢失。
- AC-002：最终有效usage按预留时价格版本结算，缓存缺失按普通输入价；未知usage、失败、取消及崩溃保留预留额，不能因为时间过去而自动释放。
- AC-003：多进程/连接共用月池，竞争最后额度最多一个成功。settle重复相同report幂等，冲突report拒绝，不能双扣或释放他人预留。
- AC-004：按DB时钟UTC自然月选择period，跨月迟到结算仍归预留月份。模型或价格不匹配、无效配置拒绝；账本不保存Prompt/回复/密钥。
- AC-005：实际费用大于预留时保存真实费用并暂停该月池新增调用，要求管理员核对价格/估算；不能将费用截断为预留额。应用预留不承诺供应商账单硬封顶。

预留输入token上界估算初值为完整messages/schema序列化UTF-8字节数加1024协议开销，输出为请求max_completion_tokens=512；缓存按无折扣预留。此估算必须用选定供应商校准，不能宣称适用于任意tokenizer/隐藏开销。供应商消费上限和总预算余量仍必须配置。

公开审计snapshot提供月份、limit/reserved/spent/blocked；调用审计按call_id查询。后续实现70%提醒/90%低优先级停止、管理预算变更、账单核对及其他服务共享此池；本规格不自动采购、选择收费模型或动态获取价格。

# SPEC-023：模型上下文中的引用关系

状态：Verified（上下文关系与裁剪；模型引用发送另行验收）。沿用回放入口，观察模型生成服务接收的上下文。

每条可见消息获得 message_ref；入站 reply 段在模型上下文中显示 replies 数组，每项包含 status 与 target_ref。目标只在当前会话、实际保留的上下文内解析：唯一匹配为 resolved；不存在或已被裁剪为 missing；消息 ID 重复为 ambiguous。缺失或歧义目标的 target_ref 为 null，不猜原文、不跨会话查找、不自动联网获取。

参与判断与生成回复都使用此上下文。保留原有最多 30 条、单条文字 1000 字、上下文 JSON 12000 字限制；裁剪后重新解析，不能保留指向已删除消息的引用。

本规格解决模型理解群友引用关系；模型发出引用选择和平台发送后核对另行接线，不宣称已完成。

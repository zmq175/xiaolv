# SPEC-024：模型引用选择、目标核实与发送读回

状态：Verified（本地闭环及群/好友协议，真实 QQ 待验收）。沿用在线入口、回放与 DeliveryService 边界。

启用引用能力的会话输出 reply_to=null 或可见 message_ref。服务端解析当前会话唯一的消息 ID，拒绝未知/被裁剪/歧义目标；运行时再次核实。引用独立于 mentions，允许组合，不默认 @。

只读准备通过 get_msg 核实目标 ID 和群/好友会话范围。群匹配 group_id；好友入站目标须为 sub_type=friend、user_id=当前好友，不能把临时私聊当好友。随后最终 TTL/epoch 认领，发送原生 reply。平台接受后读回返回的 message_id，检查当前群/好友范围和唯一匹配的 reply 段。读回失败、段缺失/不匹配、超时均 unknown，不重发；发送前核实失败为 not_sent。

读回针对 SnowLuma 转换后缓存事件，可检测已知的静默丢段，不证明真实客户端显示或对方收到。缓存原始数据可能与 QQ 最终呈现不同，真实验收仍必要。发送前后网络操作分别受现有准备和发送期限约束。

验收：在线模型选引用→原生发送→读回核对；引用与@组合；目标跨群拒绝；未知引用不查询；读回丢段 unknown且不重发；无引用保持原有行为。好友分支必须另有协议用例，不能仅从群聊测试推断。

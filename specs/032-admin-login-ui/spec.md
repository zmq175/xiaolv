# SPEC-032：浏览器管理登录

状态：Verified（本地Chromium桌面/手机视口及真实认证服务；部署与其他浏览器待完成）。用户已确认浏览器、HTTP、聊天联动测试边界。本切片以真实浏览器验证已有登录会话接口，不用前端假接口冒充接通后端。

React + TypeScript + Vite前端位于dashboard；构建为静态资源，由独立FastAPI管理服务同源提供/admin/，不增加常驻Node服务。未构建时/admin/返回明确503提示，认证API仍可用。部署使用npm ci和npm run build；禁止把秘密打入前端包。

登录页不固定机器人名字，标题为机器人管理。只提供密码输入、明确的登录操作、检查会话/提交中状态、错误和重试。正确登录后显示实际认证状态及退出按钮；不放尚未实现的配置按钮或伪造运行数据。刷新检查服务端会话，退出须撤销真实会话；网络错误不能冒充退出成功。CSRF只在内存，密码提交后清空，不写localStorage/sessionStorage。

- AC1：浏览器打开真实服务，错误密码显示错误，正确密码登录、刷新保持会话、退出后刷新仍未登录。
- AC2：网络失败和限速有可读提示；提交时防重复；恢复可重试。
- AC3：桌面1280×800、手机390×844无横向溢出，标签与键盘焦点可用，静态资源正常。
- AC4：真实服务同源提供构建资源，API路由不被SPA吞掉；缺构建时明确报错。

默认本机/SSH部署策略不变；配置发布、仪表盘数据与运行时联动后续实现。浏览器测试使用隔离PG及合成密码，截图仅本地临时文件，不上传会话或截图。

# 实施顺序

1. 配置公共入口：默认关闭、显式会话授权、预算和次数边界，先红后绿。
2. 官方模型SDK原生function tools及有界LangGraph循环；依旧通过聊天入口验收，测试替身仅在外部模型/网络/时钟边界。
3. 接Tavily官方SDK Search、会话URLRef和Extract，结果/正文/来源进入有界工具上下文；失败可观察，不自动长期入库。
4. 持久credit账本与跨实例并发控制；接线前验证未知费用和重启行为。
5. 在线与控制面配置、真实本地HTTP/PG组合回归；文档同步与实际供应商样本清单。

禁止跳过原生工具循环而让每次回复固定先搜索。实际供应商密钥、收费调用和QQ灰度在准备好可审查配置后单独验收；当前无需这些信息即可继续开发。

Credit账本实现：独立于金额池，按服务端UTC月及统一tavily池计数，Search与后续Extract共用；PG numeric/Decimal保存数值。basic搜索预留1 credit，响应中可信的usage.credits决定实际扣费，缺失/非法usage或请求失败保持预留。请求结束后若费用大于预留，记录实际费用并冻结本月后续请求。数据库事务只做预留/结算，不包住网络。重启、异常与并发验收继续从聊天入口观察供应商请求次数，不直接断言内部表。

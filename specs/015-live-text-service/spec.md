# SPEC-015：在线文字服务接线与启动

状态：Verified（本机组合验证，真实平台待验收）。测试边界为配置、完整入站回放与原生发送出口。

`run_live(settings, stop)`组合真实OneBotWebSocket、入站/候选PG、LangGraph、ChatCompletionsGateway和PostgresModelBudget/DeliveryLedger。只使用显式服务配置；线上模式强制绑定费用账本。`python -m xiaolv`按mode选择原有本地replay或在线服务，配置错误不输出密钥。

- AC-001：live必须配置QQ self_id、模型provider/price_version/单价、模型月额度；模型费用独立配置，不设置200元固定上限。固定部署开销为可选规划信息，不参与模型额度校验。群/私聊allowlist默认空，仅明确启用会话能调用模型/发送。列表是JSON正整数数组，不支持@all或通配。
- AC-002：在线启动先检查数据库迁移，再校验get_login_info的登录账号等于配置；无效/错账号回执中止，模型HTTP零调用。启动恢复过期回合和sending状态；不自动升级数据库，不采购、不自动选择模型。
- AC-003：真实本机WebSocket事件→PG去重/合并→HTTP模型→PG费用与发送认领→OneBot原生文字发送能够闭环；沉默/过期/预算拒绝不发送，重复推送不重复回复。
- AC-004：入站不等待模型；畸形事件计数并跳过，连接或数据库故障停止服务，不能后台静默丢事件后继续发送。此阶段不自动重连；进程重启依靠持久去重和到期检查。
- AC-005：stop停止接收和新认领；活跃worker最多等待5秒完成，再取消并落unknown/保留费用。故障退出直接取消worker，释放客户端与DB连接。run_live返回不含正文的处理统计，失败抛经过分类的错误。
- AC-006：默认入口仍为无凭据离线演示；文档提供迁移和在线配置/启动命令。真实QQ/模型/费用与自然度未测试，不以本机服务模拟冒充灰度验收。

临时私聊保留入站隔离但没有自动发送路由；本规格不实现管理面动态授权、成员同步/LLM选择@、图片/语音或完整群级发送配额。2026-09-29用户澄清：200元仅作为部署成本评估参考，不限制模型费用。固定月开销为可选信息，由管理员按主机续费摊销、备份等填报，不能从机器套餐名推测；额度字段不使用真实价格默认值。

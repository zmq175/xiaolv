# SPEC-027：跨进程模型并发名额

状态：Verified（PG 共享准入、取消与真实 SIGKILL 恢复；供应商行为待验收）。沿用回放/在线入口，通过外部模型 HTTP 是否发生验证。

在线网关在进程内信号量之外使用 PG 共享名额池 chat-model，容量来自 model_concurrency。名额获取在费用预留之前；等待计入同一回合截止时间，不重置模型 TTL，不占预算。短事务锁池记录、清理过期租约、检查容量并插入唯一 call_id 租约，网络调用不持有 DB 行锁。

租约到原始回合 deadline 后额外保留 5 秒用于取消/清理；正常完成释放，进程崩溃后由后续申请惰性回收。取消 HTTP 不代表供应商停止远端计算，本限制约束应用发起的有效调用，不承诺供应商内部运行任务严格同时结束。暂停的进程恢复后仍受原截止时间限制。

池容量持久化，各实例配置不一致拒绝调用，不能默默放宽。首版启动检查容量一致性；动态调容管理接口另行实现。无共享名额对象只用于现有独立协议测试，在线必须绑定。

验收：不同连接/网关竞争容量 1 时至多一个进入 HTTP；等待超期没有供应商请求和费用预留；成功/取消后释放；崩溃或过期租约不永久占位；配置不一致失败关闭；完整在线回归。SIGKILL 崩溃验证与真实供应商取消行为需分别报告证据范围。

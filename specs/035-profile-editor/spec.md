# SPEC-035：浏览器人设编辑与发布

状态：Verified（本规格限定范围）。沿用已确认浏览器/HTTP/聊天测试边界；使用webapp-ui-skill，本地合成数据验证。

登录后可编辑名称、每行一个别名、人设、参与风格和回复风格。首次无草稿显示空表单与未发布说明，不把默认人设当作实际运行配置。表单区分未保存、已保存草稿、已发布版本；保存草稿不会发布。发布只针对服务端草稿，未保存修改时禁止发布，避免发布与屏幕不同内容。显示下一回合采用的说明，不冒充所有运行实例已经生效。

写请求带当前管理version、CSRF、随机幂等键。请求进行中禁止编辑和重复提交；网络失败结果未知时保留同一请求与幂等键，明确提供重试，不能另建操作重复执行。409保留本地编辑并提示重新加载会丢弃本地内容，由用户点击明确按钮。422展示字段错误，401回到登录；403提示刷新登录状态。资料仅驻留内存，不放浏览器持久存储。

- AC1：桌面/手机通过真实页面登录、编辑、保存、刷新、发布；草稿保存后未发布，发布后显示版本。
- AC2：读取失败可重试，写操作中控件禁用，响应丢失后同键重试不会新增版本。
- AC3：并发修改409不覆盖本地内容，明确重新加载后看到最新草稿；会话过期退回登录。
- AC4：字段错误可定位；无横向溢出、控制台错误；键盘焦点可见。

本轮不含历史版本选择/回滚网页、差异对照及运行实例概览；已有HTTP回滚能力保留，后续继续补齐。无数据库迁移或外部付费调用。

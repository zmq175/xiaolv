## 首个网页闭环

1. 登录、退出、会话过期提示。默认本机入口，通过SSH隧道使用；Cookie策略必须与实际HTTP/HTTPS部署匹配。
2. 概览显示已有可靠数据：连接/心跳、最近回合结果、超时与未知回执、模型用量。暂无数据与离线明确区分，不展示模拟指标冒充运行状态。
3. 机器人资料表单编辑名称、别名、人设、参与风格和回复风格。名称来自BotProfile，管理页标题亦不得固定为“小绿”。
4. 草稿校验、查看差异、发布与回滚。展示字段错误、并发修改冲突、已发布版本与运行时已采用版本；保存草稿不等于生效。
5. 会话启停与紧急撤权接入真实聊天出口；不能只更新界面开关。普通风格调整下一回合采用，撤权在副作用前重新检查。

后续按06的页面分组接入人物学习、媒体、知识库、Skill/MCP和任务。尚未实现的功能不呈现可操作的假按钮。管理网页不是单独一个Swagger接口页，也不把安装能力暴露到QQ。

# 在线文字服务（开发验证）

此入口已通过本机 PostgreSQL、HTTP 模型服务与 OneBot WebSocket 合成联调；未登录真实 QQ，也未验证供应商效果和收费。首版其他功能尚在开发，当前不代表可无人值守上线。支持 Linux/WSL 的 SIGINT/SIGTERM；默认运行离线演示。

## 配置与启动

使用 Python 3.12 与锁定的 uv 环境。配置从进程环境读取，程序不会自动加载 `.env`。可将 `.env.example` 复制为本地 `.env`，自行填写私密值，通过 shell 或服务管理器注入；不要提交或公开这些文件。

```sh
uv sync --locked
# 仅在本地配置文件可信且符合 shell 语法时使用：
set -a
. ./.env
set +a
# 显式应用迁移，不由服务自动执行：
uv run alembic upgrade head
PYTHONPATH=src uv run python -m xiaolv
```

在线模式需要 `XIAOLV_MODE=live`，并设置数据库 DSN、模型接口地址/密钥/模型 ID、供应商标识、价格版本、人民币每百万输入/输出 token 单价、模型月额度、OneBot WebSocket 地址/token、QQ 登录账号 ID。部署时为模型使用 HTTPS、为远程 OneBot 使用 WSS；本机模拟允许 loopback HTTP/WS。密钥通过请求头发送，不能放入 URL。

模型请求与SSE解码使用官方openai Python SDK，不维护自写SSE解析器。SDK自动重试关闭，首内容/空闲/整轮截止时间由应用控制；原始流模式保留用量字段用于严格计费校验。当前请求identity编码并拒绝压缩模型响应，真实供应商需验证支持情况。

单价和额度必须由管理员填写，不提供真实价格默认值；价格版本供历史结算审计，缓存价可选。`XIAOLV_MONTHLY_EXTERNAL_BUDGET_CNY` 当前为模型池额度，**不受 200 元限制**，与部署成本分开；0 表示禁止新模型调用。月池按 PostgreSQL UTC 自然月结算。同一月份已建立额度后，配置不能静默改写账本额度；运行中调额需后续管理能力。`XIAOLV_MONTHLY_FIXED_COST_CNY` 是可选部署规划信息，不参与额度校验，不要求填写。

会话默认全部关闭。使用 JSON 整数数组启用指定群或私聊，例如 shell 配置：

```sh
XIAOLV_ENABLED_GROUP_IDS='[20000]'
XIAOLV_ENABLED_PRIVATE_IDS='[]'
```

数字仅为合成示例，替换为自己授权的目标；不支持通配或 @all。未启用会话的有效消息仍会存储为隔离的入站历史，但不会创建回复候选、调用模型或发送消息。临时私聊只接收，不建立发送路由。

机器人名字、别名、人设和表达风格通过可选 `XIAOLV_BOT_PROFILE` JSON 配置，默认为小绿，重启生效。详见[身份配置与提示词](architecture/09-persona-prompts.md)。改名不改变平台账号、权限或消息路由。

## 启动、停机与故障

启动依次检查迁移版本、调用原生 `get_login_info` 核验机器人账号、恢复遗留状态，然后启动接收和有界 worker。迁移不匹配或账号错误会中止；不会自动登录账号或改库。过期 running 回合标记 expired，过期 sending 标记 unknown，不补发。未知模型费用保留预留，不当作免费调用。

SIGINT/SIGTERM 停止新接收和新认领，给活跃 worker 最多 5 秒完成，再取消；清理还可能涉及费用结算和数据库操作。断线或数据库故障会停止整组任务，不在后台无限重连。重启复用持久去重与截止时间，不能通过重启补发旧消息。

正常退出 stdout 输出 JSON 处理计数，不含消息正文；已分类的运行故障返回退出码 1，配置错误返回 2，默认离线演示返回 0。应用日志已接标准logging和OpenTelemetry，写stderr，可选本地轮转文件，见[日志运行方式](logging.md)。完整跨队列trace传播、指标与管理控制面仍未完成；终止统计不是完整运行监控。

## 验收和限制

本机测试覆盖原生收发闭环、账号/迁移门控、去重、会话白名单、沉默、额度拒绝、非法事件、模型卡住后停机、连接中断、真实子进程 SIGTERM 以及超过一批的启动恢复。

真实环境还需验证 SnowLuma 锁定版本认证及事件行为、QQ 账号和测试群、模型结构化输出与 usage、实际延迟/费用、自然度。已接通模型选择 @ 与引用、动态成员核实、引用发送前目标查询及发送后读回；会话冷却和滚动窗口配额由 PG 共享。仍没有动态撤权、跨进程模型并发限制、媒体、长期记忆、知识库和主动发言。成员查询的实际新鲜度、QQ 通知和引用显示仍待实测。

部署与生产备份恢复仍未验收。数据库迁移 0005 包含模型费用账本，禁止将降级清表作为普通回滚；代码回滚须保持当前数据库版本兼容，先保留数据库备份和审计记录。

## 发送频率

`XIAOLV_DELIVERY_POLICY` 是 JSON 配置，默认 `{"cooldown_seconds":5,"window_seconds":60,"max_messages":6}`。群与好友会话分别计数：sending、confirmed、unknown 均占用额度，明确 not_sent 会释放；rate_limited 为持久终态，不排队等冷却、不因重启再发送。限制按发送认领时间执行，不等于远端客户端精确到达间隔。

所有实例应使用一致的管理配置。模型调用前已增加只读配额预判，明显处于冷却或额度已满的回合不调用模型；预判后可能被其他实例抢占额度，因此最终原子认领仍必须复核，少数竞争回合仍可能产生模型费用后限流。迁移 0007 将旧记录认领时间保守设为迁移时刻，可能暂时占用一个窗口；不要删除历史发送记录来绕过配额。
